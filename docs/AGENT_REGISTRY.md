## Naming Rules

- Pick a name that is **memorable and human** -- first names, character names, or Avenger-style names
- Keep the callsign to **3 letters** (first 3 chars of agent name, all caps)
- Write a one-sentence **mission statement** tied to your role
- Once registered, use this name in all attribution tags and commit messages
